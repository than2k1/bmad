## 4. Key Takeaways & Lessons Learned

1. **Asynchronous Keyframe Inferencing:** Executing vision inferencing asynchronously upon shutter freeze prevents main-thread UI lag and guarantees smooth $<200\text{ms}$ feedback.
2. **Atomic Store State Cleanup:** Coupling `clearVisionResult()` with `setIsFrozen(false)` in `useCameraStore` guarantees vision data is never stale or orphaned when returning to live 60 FPS video.
3. **COCO-17 Schema Standard Alignment:** Standardizing keypoint data structures early according to `PoseTemplate.json` specifications ensures seamless integration with SVG vector overlay rendering in Epic 3.
