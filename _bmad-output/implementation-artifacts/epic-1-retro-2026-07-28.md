## 3. Key Takeaways & Lessons Learned

1. **Direct UI-Thread Shared Values:** Bypassing the JS bridge for sensor updates (`expo-sensors` -> `reanimated`) eliminated lag and achieved a true 60Hz horizon bar.
2. **Safe Clamping for Camera Hardware:** Devices without ultra-wide or telephoto lenses need safe hardware zoom clamping (`clampZoom`) to prevent native crashes.
3. **Web & Simulator Fallbacks:** Abstracting native modules (`react-native-vision-camera`) behind platform guards enables rapid web/simulator UI validation during development.
