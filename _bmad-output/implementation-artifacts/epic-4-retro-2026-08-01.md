## 4. Key Takeaways & Lessons Learned

1. **Shared hook pattern is the project standard.** `useLensGuidance.ts` proved that pulling engine computations into a hook eliminates duplicate computation across overlay components and gives a single place to fix layout/viewport bugs. **Apply this pattern to Epic 5 composition rule guidance.**
2. **Hardcoded layout offsets are accumulating.** Every overlay shipped with at least one absolute pixel offset that wasn't safe-area aware. 4.2 fixed it; 4.3 deferred it. Pattern needs a holistic audit before Epic 5 adds more overlays.
3. **State reset on mode transitions is a recurring edge case.** 4.3 patched two stale-UI bugs (`gridMode` linger, `sceneType: undefined` badge). Same shape as Epic 3 keyframe cleanup. Worth a defensive `useEffect` cleanup convention.
4. **Spec/code drift closes slowly.** 4.3 shipped a cyan stroke for Golden Ratio despite AC #2 specifying white. Decision was "intentional per-mode color differentiation" — but spec was never updated. Doc and code now disagree.
5. **Architecture spine discipline held.** Every story cited AD-2 (keyframe pipeline) and AD-5 (state). Engine utilities stayed pure; overlays stayed thin. Zero exceptions across the epic.
